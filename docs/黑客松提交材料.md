## 一、作品基本信息

- **作品名称**：运维值班台 · 全能工作台（Ops Center）
- **一句话简介**：面向政府/事业单位信息中心的值班工作台——不替换现有监控/备份/资产系统，把多源数据组织成「本班必须处理什么、交给谁」，并自动生成可审计的交接班。
- **赛道方向**：AI + 政企数字化 / 办公效率（按表单实际选项调整）

## 二、作品简介（约 300 字，可直接粘贴）

统计局、政府内网的值班人员每天要在监控、备份、资产台账和变更记录之间来回切换。原始告警重复、备份是否超时需要人工判断、资产风险分散在表格里，交接班又依赖手工整理。真正影响值班效率的，不是"没有数据"，而是数据没有被组织成可执行的事项。

「运维值班台」不替换现有系统，而是把告警、备份、资产和交接班串成一个值班闭环：按主机+服务+标题合并告警并保留次数与最高级别；按日备/周备双阈值判断备份时效；对资产台账执行证书到期、责任人缺失、无备份、单机多关键服务检查；最后自动生成一页交接班。升级版「全能工作台」在此之上加入备份核查工单、任务待办、日程会议、报告生成与 AI 助手：助手用自然语言跨模块回答问题，每个结论都标注调用了哪些工具、引用哪条证据——规则引擎出事实，AI 只做组织，不编造数字。

演示数据中：6 条原始告警合并为 5 条事件；4 个备份任务全部识别出时效异常（含 1 项无成功记录、最长 244.7 小时未成功）；16 项资产统一搜索并发现多类风险。值班人员看到的不再是数据列表，而是"现在必须处理什么、为什么、交给谁"。

## 三、核心亮点（按表单字数限制取舍）

1. **值班视角，不是大屏**：终点是事项被确认、处理、交接，全程审计留痕。
2. **规则出事实，AI 做组织**：每条结论带工具调用轨迹和证据字段，杜绝 AI 幻觉数字。
3. **只读接入、数据不出域**：CSV/导出文件接入，不登录不执行不改现有系统；支持内网离线部署与本地模型。
4. **轻**：单文件 Python 服务 + 浏览器 UI，信息中心 1–2 天可装完；另有 Kindle 白底看板。
5. **可扩展为 Agent 工作台**：已有完整设计方案（工具注册 + Agent 循环 + 对话界面），90 天商业化路径清晰。
