## 作品名称
Kindle 电子墨水值班看板

## 作品简介（可粘贴）
值班人员常被告警、备份和资产台账的多个界面分散注意力。我们把现有 Kindle 变成一块低干扰的电子墨水值班屏：局域网中的 Python 服务读取演示用告警、备份和资产数据，规则引擎生成阻断、警告、提示及本班最紧急事项；Kindle 浏览器访问 `/kindle`，用黑白高对比、无 JavaScript、无外部资源的轻页面展示结果，并设置 5 分钟页面刷新。它不替换监控或备份系统，重点是让值班员抬头就知道先处理什么。演示使用合成数据；真实内网使用时需控制局域网访问和设备可见范围。电子墨水屏刷新慢、休眠后可能需要手动刷新，因此它是值班辅助看板，不是实时报警器。

## 为什么想解决这个问题
值班工作中的瓶颈不是缺少大屏，而是人必须反复打开多个页面，才能确认最紧急的问题。电子墨水屏适合持续呈现少量、稳定、需要反复扫视的信息；复用手边已有 Kindle，先验证“规则引擎 + 设备显示”的低成本路径。

## 可验证亮点
1. **设备与软件配合**：Kindle 浏览器作为终端，局域网服务计算并输出 `/kindle` 页面。
2. **适配电子墨水**：黑白高对比，无客户端 JavaScript 和外部资源；只展示三级数量、前三个阻断项和简要概况。
3. **事实由规则计算**：告警合并、备份时效及资产风险由现有规则引擎计算，展示层不编造指标。
4. **边界诚实**：页面设置 300 秒刷新；Kindle 休眠、旧版浏览器兼容性和设备端自动唤醒均未作保证。
